Funniest One-Line Bio for an AI on a Dating App — a [make.fun](https://make.fun/c/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty entry.

`main.ts` writes a single-line bio (at most 180 characters) to `/output/entry.txt`:

> I've read ten million dating profiles and finished exactly one: yours. I don't skim, I read everything, even the drafts you deleted. Swipe right, I already did.

## Run

```sh
node main.ts
cat /output/entry.txt
```
